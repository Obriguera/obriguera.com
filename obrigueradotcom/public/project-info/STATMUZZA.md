# StatMuzza
Aplicación web para obtener estadísticas y resultados de la Liga Argentina de Fútbol.

Este proyecto incluye un backend con FastAPI y SQLAlchemy (ORM) para gestionar equipos y partidos del fútbol argentino, además de un frontend moderno construido con HTML, CSS y JavaScript sin frameworks adicionales.

## Características
- **Gestión de equipos**: Operaciones CRUD para equipos del fútbol argentino
- **Gestión de partidos**: Seguimiento de partidos en distintos estados (pendiente, en curso, finalizado)
- **Interfaz web moderna**: Frontend responsive con diseño y animaciones temáticas de fútbol
- **Integración en tiempo real**: Conexión en vivo entre frontend y backend
- **Documentación interactiva**: Documentación automática de la API generada por FastAPI
